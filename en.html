Industry–Academia Collaboration — Enterprise Internal Knowledge Q&A System

×

Role: Project technical point of contact｜Period: Aug 2024 – Apr 2025

An on-premise RAG system built under strict security constraints. The client required that data never touch external cloud AI services, so the entire system uses locally deployable open-source components and runs without any external API.

System Architecture

  • Document processing: parses PDF／Word／Excel process and quality-inspection documents into a unified indexable text format
  • Retrieval: LlamaIndex pipeline with ChromaDB for vector storage, plus a Reranker for two-stage reordering to improve context precision
  • Generation: gemma3:27b-it-qat deployed on-premise via Ollama, using the quantized build to fit local hardware
  • Data layer: PostgreSQL／SQLAlchemy records dialogue history, retrieved source passages, user feedback and system logs, so every response can be traced back to its source document
  • Interface: Gradio combines Q&A and knowledge base management, wrapping file upload/deletion and index rebuilding into a graphical workflow
  • Operations: hardware resource monitoring and system logging modules

Quality Validation

Adopted RAGAS to quantify system performance across answer relevancy, faithfulness, answer similarity and context precision, giving the client and the team a shared language for evaluating results.

NSTC Project｜Digital Support, Barrier-Free Communication

×

Full project title: “Digital Support, Barrier-Free Communication: Development, Support and Promotion of AI-Assisted Communication Aids for People with Speech and Language Disabilities”

One RAG architecture with eight independent knowledge bases, helping people with speech disabilities and their caregivers look up assistive-device applications and event donation information across seven organizations.

System Architecture

  • Core: RAG vector retrieval with a Reranker, reducing hallucination and improving answer accuracy
  • Knowledge base: crawled each organization's website and merged it with existing FAQs, keeping a separate knowledge base per organization to avoid cross-contamination
  • Generation: LLM API integration handling multimodal input and cross-lingual queries
  • Interface: LINE Messaging API, so users do not need to install anything new
  • Deployment: 8 independently deployed services on Google Cloud Run within a single GCP project

Replicability

The core architecture stays fixed; differences between organizations live only in the knowledge base content and dialogue settings. Adding an organization requires no new development — copy the deployment, swap the knowledge base, go live. Eight rollouts were completed during the project, and the systems have run for nearly 2 years serving 2,000 cumulative messages.
